# Agent notes

This repository documents and automates Termux setup.

- Keep setup steps idempotent and preserve the documented recovery path.
- Validate changes in a disposable Termux environment when possible; do not
  put personal device names or private configuration values in examples.
- Before adding or changing workflows, check for reusable workflows or actions
  in [ci-workflows](https://github.com/pschmitt/ci-workflows) and preserve
  existing caller behavior and check coverage.
